Validación desde tu APK

La APK debe enviar la key a tu servidor y recibir si es válida. Esta dirección es solo un ejemplo; todavía no existe un backend conectado.

No pongas una clave secreta de administración dentro de la APK. La validación y la administración real deben hacerse en un servidor.

Ejemplo de solicitud

POST /api/v1/keys/validate
Content-Type: application/json

{
  "key": "POCOYO7X-AB12"
}

Ejemplo de llamada desde JavaScript

const respuesta = await fetch("https://TU-DOMINIO/api/v1/keys/validate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ key: keyIngresada })
});

const resultado = await respuesta.json();
// Tu servidor debería responder, por ejemplo:
// { "valid": true, "expiresAt": "..." }

Para usarlo de verdad falta crear la API, una base de datos y un inicio de sesión seguro para el panel.
